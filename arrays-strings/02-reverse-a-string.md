# Reverse a String

**Difficulty:** Easy

**LeetCode:** https://leetcode.com/problems/reverse-string/

## Approach

I used two pointers, one starting from the beginning and one from the end. I swapped the characters and moved both pointers towards the center until the string was reversed.

## Complexity

- Time: O(n)
- Space: O(1)

## Notes

I learned how to reverse a string in-place using two pointers. I also tested the solution locally before submitting it to LeetCode.
