# Valid Anagram

**Difficulty:** Easy

**LeetCode:** https://leetcode.com/problems/valid-anagram/

## Approach

I used a frequency array of size 26 to count the occurrences of each lowercase letter in both strings. If the counts match for every letter, the strings are anagrams.

## Complexity

- Time: O(n)
- Space: O(1)

## Notes

I learned how a frequency array can be used to compare the characters of two strings efficiently.
